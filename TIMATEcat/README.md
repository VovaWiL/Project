# 🐱 TIMATEcat

Гигантская энциклопедия всего кошачьего мира — 56 пород, беспородные, 300+ имён, 28 легендарных котов, 23 мема, факты и рекорды.

## 🚀 Как открыть

### Локально
Просто открой **`index.html`** в браузере. Всё внутри — 184 картинки вшиты в файл. Ничего скачивать не нужно.

Если картинки не показываются — очисти кэш браузера (Ctrl+F5).
